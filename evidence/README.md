# Свидетельства

Здесь хранятся только те результаты проверок, на которые ссылается [`project.md`](../project.md). Полный служебный вывод инструментов не сохраняется, если он не нужен для понимания вывода.

Каждый файл содержит: проверяемую версию (commit), дату, команду или последовательность действий, версию инструмента, существенный результат и ограничения.

К ЭК1 выполнена только ручная проверка исходного состояния — [baseline-smoke.md](baseline-smoke.md) (используется в разделе 3). Методы раздела 5 ещё не применялись; ожидаемые файлы по предварительному плану:

| Файл | Метод | Ведущий |
| --- | --- | --- |
| `lifecycle-check.md` | Метод 1. Приём, хранение и удаление файлов | Участник 1 |
| `processing-tests.txt` | Метод 2. Обработка повреждённого и неподдерживаемого входа | Участник 2 |
| `resource-limits.md` | Метод 3. Ограничения ресурсов | Участник 2 |
| `dependency-audit.txt` | Метод 4. Зависимости и состав выпуска | Участник 1 |

Набор файлов может измениться после выбора методов на лекциях 06–08.
